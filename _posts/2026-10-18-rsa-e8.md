## 1. 题目

`task.py` 生成 RSA 参数并加密 flag：

```python
e = 8
while 1:
    p = getPrime(512)
    q = next_prime(p + 2**400)
    r = getPrime(512)
    if p % 4 == 3 and q % 4 == 3 and r % 4 == 3:
        break
n = p * q * r
hint = p * q
m = bytes_to_long(flag)
C = pow(m, e, n)
```

公开实例：`C`（1534 bit）、`n`（1534 bit）、`hint`（1023 bit）。

## 2. 观察

1. `n = p*q*r` 且 `hint = p*q`，因此

   ```
   r = n // hint        # 整除，余数为 0
   ```

   实测 `r` 为 512 bit 素数，且 `r % 4 == 3`。

2. `e = 8` 与 `φ(n)` 不互素：三个素数均 ≡3 (mod 4)，各自 `p-1` 只含一个因子 2，故 `gcd(8, φ(n)) = 8`，**不存在私钥指数**，常规 RSA 解密不可用。

3. 但 flag 远小于 `r`（39 字节），于是

   ```
   C ≡ m^8 (mod r)
   ```

   在模 `r` 上求 8 次根即可恢复 `m`，不需要分解 `p*q`。

## 3. 模素数开 8 次根

`r ≡ 3 (mod 4)`，故 `r - 1 = 2 * odd`，`gcd(8, r-1) = 2`：

- `x^8 = C (mod r)` 有解当且仅当 `C` 是二次剩余，此时恰有 2 个解
- 逐层开方：`y = C^((r+1)/4)` 得 `y^2 = C`；再对 `±y` 判断二次剩余并开方得 `x^2`；再对 `±x^2` 开方得 4 个候选，保留满足 `x^8 ≡ C (mod r)` 的 2 个

得到候选后，用 `pow(x, 8, n) == C` 做精确校验：命中者即为明文（另一根是 `-m mod r`，为 512 bit 乱码）。

## 4. 求解脚本

```python
#!/usr/bin/env python3
"""task.py solver.

Insight: e=8, n=p*q*r, hint=p*q  =>  r = n // hint is known (512-bit prime).
C = m^8 mod n, so C = m^8 (mod r).  gcd(8, r-1) = 2, so x^8 = C (mod r) has
exactly two roots; if the plaintext m < r (flag < 64 bytes) one of them IS m.
No need to factor p*q at all; the answer is then verified by x^8 == C (mod n).
"""
import re, sys

def roots8(Cv, P):
    """all x with x^8 == Cv (mod P); P prime, P % 4 == 3."""
    Cv %= P
    if Cv == 0:
        return [0]
    if pow(Cv, (P - 1) // 2, P) != 1:      # C must be a QR
        return []
    out = set()
    y0 = pow(Cv, (P + 1) // 4, P)          # y0^2 = C
    for y in (y0, P - y0):
        if pow(y, (P - 1) // 2, P) != 1:   # need y QR  (x^4 = y)
            continue
        s0 = pow(y, (P + 1) // 4, P)       # s0^2 = y
        for s in (s0, P - s0):
            if pow(s, (P - 1) // 2, P) != 1:   # need s QR (x^2 = s)
                continue
            x0 = pow(s, (P + 1) // 4, P)
            for x in (x0, P - x0):
                if pow(x, 8, P) == Cv:
                    out.add(x)
    return sorted(out)

src = open(sys.argv[1] if len(sys.argv) > 1 else "task.py").read()
C    = int(re.search(r"^C=(\d+)", src, re.M).group(1))
n    = int(re.search(r"^n=(\d+)", src, re.M).group(1))
hint = int(re.search(r"^hint=(\d+)", src, re.M).group(1))

r, rem = divmod(n, hint)
print("r = n/hint  exact=%s  bits=%d" % (rem == 0, r.bit_length()))

for x in roots8(C, r):
    m = x.to_bytes((x.bit_length() + 7) // 8, "big")
    ok = pow(x, 8, n) == C
    print("candidate bits=%d  verify_mod_n=%s  text=%r" % (x.bit_length(), ok, m))
    if ok and all(32 <= c < 127 for c in m):
        print("FLAG:", m.decode())
```

## 5. 说明

- 题目代码给出了 `q = next_prime(p + 2^400)` 的近邻关系，理论上可由 `p0 = (-2^400 + isqrt(2^800 + 4*hint)) // 2` 在 `p0` 邻域内搜索因子来分解 `hint`。对该实例做了 ±5,000,000 的扫描与判别式检验，未命中，说明实例的 `p、q` 并非该构造（实例值可能由另行生成）。本方法不依赖这一点。
- 若明文长度使 `m >= r`，模 `r` 的开根只能得到 `m mod r`，此时需要另一条路径；本实例不涉及。
- 存在性前提：`C` 必须是模 `r` 的二次剩余——由 `C = m^8 mod n` 直接保证。

## 6. 修复建议

- `e` 必须与 `φ(n)` 互素（用 `e = 65537`），不要用 2 的幂
- 加密前做 OAEP / PKCS#1 v1.5 填充，避免小空间明文与确定性加密
- 不要泄露任何因子相关信息；`hint = p*q` 直接给出 `r`，等于多素数 RSA 的因子泄露
