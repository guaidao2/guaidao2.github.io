## 1. 附件

```
loader        ELF64 用户态程序（PIE，动态链接，strip）
wm_kmod.ko    Linux 内核模块
```

运行链路：`loader` 打开 `/dev/wmqddbh`，向模块索取 16 字节 seed，用 seed 作为 RC4 密钥解密内嵌载荷，校验 CRC32 后把载荷 `mmap` 成可执行并跳入。

## 2. loader 静态分析

### 2.1 内嵌容器

`.data` vaddr `0x40a0`：

| 偏移 | 值 | 含义 |
|------|-----|------|
| 0x00 | `"WMPK"` | magic |
| 0x04 | `0x02` | version |
| 0x08 | `0x24b` | 载荷内入口偏移 |
| 0x0c | `0x2000` | 载荷长度 |
| 0x10 | `0xf8ebcbbe` | 明文 CRC32 |
| 0x14 | `0x2000` | 长度副本（必须相等） |
| 0x18 | … | 载荷（0x2000 字节，正好填满 `.data`） |

### 2.2 主流程

```c
fd = open("/dev/wmqddbh", O_RDWR);
struct wm_seed_req { u8 nonce[8]; u8 seed[16]; } req = { {0x3f,0xa7,0x51,0xc4,0x9b,0x2e,0xd8,0x66}, {0} };
ioctl(fd, 0xc0185701, &req);
```

随后：

1. 复制载荷到堆缓冲区，用 `req.seed` 作 16 字节密钥做标准 RC4（KSA `S[i]=i`、`j=(j+S[i]+key[i%16])`、PRGA 标准）
2. 对解密结果算 CRC32（init `0xffffffff`、反射多项式 `0xedb88320`、末尾取反，等价于 `zlib.crc32`），必须等于 `0xf8ebcbbe`，否则清零缓冲并退出
3. `mmap(NULL, len, PROT_READ|PROT_WRITE, MAP_PRIVATE|MAP_ANONYMOUS)` → `memcpy` → `mprotect(RX)` → `call payload + 0x24b`

调用时构造的结构体：

```c
struct call_arg {
    u32 magic;        // 0x574d4354 == "TCMW"
    u32 fd;           // 传给 stage2，用于后续 ioctl
    u8  nonce[8];     // 0x66d82e9bc451a73f
    u8  seed[16];
};
```

另外：`argv[1]` 以 `-` 开头时进入 verbose 分支，会打印 `[*] nonce :` 与 `[*] seed  :`。

## 3. wm_kmod.ko 分析

### 3.1 ioctl 分派

| 命令 | 大小 | 语义 |
|------|------|------|
| `0xc0185701` | 0x18 | SEED：`wm_seed_req{u8 nonce[8]; u8 seed[16]}` |
| `0xc0445703` | 0x44 | BLOB：返回 `wm_blob{u32 len; u8 data[64]}`，`len = 0x13` |
| `0x40205702` | 0x20 | VERIFY：`wm_tag_req{u8 tag[16]; u8 rsv[16]}` |

### 3.2 SEED 算法

```
mix1：eax = 0x9e3779b9, edx = 0x7f4a7c15
      对 nonce 的 8 字节：
          eax ^= b
          ecx = (b + edx) & 0xffffffff
          eax = eax * 0x1000193
          ecx = rol32(ecx, 5)
          eax = eax - 0x7a143595
          edx = (eax >> 3) ^ ecx

mix2：8 轮（T = wm_mix_key[0..7]）
          edx = edx * 0x19660d
          eax ^= T[r] << ((r & 3) * 8)
          edx = eax + edx + 0x3c6ef35f

展开（T = wm_mix_key[0..15]）：
          seed[k]    = (eax >> 8k) & 0xff
          seed[4+k]  = (edx >> 8k) & 0xff
          seed[8+k]  = ((eax ^ edx) >> 8k & 0xff) ^ T[8  + k]
          seed[12+k] = ((eax + edx) >> 8k & 0xff) ^ T[12 + k]
```

关键数据（来自带符号的模块）：

```
wm_mix_key  16B  = 8e1d4c77b32ae569910f7dc635a258e0
wm_tail_ct  19B  = 80766664c4aa93a736c8451d4afaa26ab87669
g_seed      16B  (bss，SEED 后写入)
```

### 3.3 VERIFY 算法

```
eax = 0xc2b2ae35
对 16 字节输入：eax ^= b; eax *= 0x1000193; eax = rol32(eax, 11)
eax ^= 0xa5a5f00d
对 k = 0..15：
    eax = eax * 0x19660d + 0x3c6ef35f
    tag[k] = ((eax >> 24) & 0xff) ^ wm_mix_key[k] ^ g_seed[(k+5) & 0xf] ^ 0x5a
与用户传入的 tag 比较
```

## 4. 一个必须注意的坑：发行包的 .ko 被 strip

`reverse.zip` 中的 `wm_kmod.ko` 没有 `.symtab`、没有 `.rela.*`：

```
$ insmod wm_kmod.ko
insmod: ERROR: could not insert module wm_kmod.ko: module has no symbols (stripped?)
$ readelf -r wm_kmod.ko      # 无重定位
```

反汇编中所有跨符号引用都表现为 `call rel32=0`、`[reg+0x0]`（原始 `.o` 的 addend 在 `.rela` 里，已随符号表一起丢失），因此 `wm_mix_key`、`wm_tail_ct` 的地址与内容无法从该文件恢复，`insmod` 也无法加载。

带符号的模块（本题提供的 hint 文件）则完整：

```
$ readelf -sW wm_kmod.ko | grep -E 'wm_mix_key|wm_tail_ct|g_seed'
    28: 00000000000001b0    16 OBJECT  LOCAL  DEFAULT   10 wm_mix_key
    27: 0000000000000190    19 OBJECT  LOCAL  DEFAULT   10 wm_tail_ct
    29: 0000000000000010    16 OBJECT  LOCAL  DEFAULT    7 g_seed
$ readelf -h wm_kmod.ko | grep Type
  Type: REL (Relocatable file)      # 且含 .rela.text 等
```

## 5. 计算 seed

手工按汇编写算法容易出错（尤其是展开阶段 `T[8+k]`/`T[12+k]` 的取法与末组写偏移）。更稳的做法是：**对带重定位的模块应用 RELA，再用 Unicorn 执行真实字节**。

`wm/emu_real.py` 做三件事：

1. 用 `pyelftools` 给每个 section 分配基址，按 `.rela.*` 修正 `R_X86_64_64 / PC32 / PLT32 / 32 / 32S / PC64`
2. 在 Unicorn 中映射 `.text/.rodata/.data/.bss`
3. 从 SEED 处理器入口执行，把 `copy_from_user` / `copy_to_user` 打桩，读取返回的 16 字节

```bash
python3 emu_real.py
# module SEED: 36f7a811d99d2fff7e65fa283a3780f0
```

## 6. 解密载荷

`wm/finish.py`：

```bash
python3 finish.py 36f7a811d99d2fff7e65fa283a3780f0 loader
# seed=... len=0x2000 expect_crc=0xf8ebcbbe got_crc=0xf8ebcbbe match=True
# wrote stage2.bin
```

`stage2.bin` 是 ELF64，入口 `0x24b`，与 loader 的调用点一致。

## 7. stage2 分析

反汇编要点（入口 `0x24b`）：

1. `ptrace(PTRACE_TRACEME, 0, 0, 0)`；失败返回 -2
2. 用传入的 `seed` 计算 16 字节 tag：

```
eax = 0xc2b2ae35
16 轮：eax ^= seed[i]; eax *= 0x1000193; eax = rol32(eax, 11)
eax ^= 0xa5a5f00d
16 轮：eax = eax * 0x19660d + 0x3c6ef35f
      tag[k] = ((eax >> 24) & 0xff) ^ T2[k] ^ seed[(k+5) & 0xf] ^ 0x5a
```

   其中 `T2` 是 stage2 内嵌表（偏移 `0x4b0`），与模块的 `wm_mix_key` **逐字节相同**

3. `ioctl(fd, 0x40205702, tag)` 握手；返回负值则 -3
4. `ioctl(fd, 0xc0445703, &blob)` 取 19 字节 blob，校验 `blob.len == 0x13`
5. 三段拼接 41 字节后 `write(1, buf, 42)`（末尾补换行）

三段公式（`t9` 在 stage2 偏移 `0x4a0`，`t13` 在 `0x490`）：

```
part3[i] = ((i*0x11) & 0xff) ^ t9[i] ^ 0x5a                       i = 0..8
part2[i] = seed[(7i+3) & 0xf] ^ t13[i] ^ seed[(i+11) & 0xf] ^ 0x6d  i = 0..12
part1[i] = seed[(5i+1) & 0xf] ^ blob[i] ^ 0x3c                    i = 0..18
flag = part3 + part2 + part1
```

## 8. 结果

直接在 Unicorn 中执行 stage2（`wm/run_stage2.py`，对 `ptrace`/`ioctl`/`write` 打桩并捕获输出）：

```
captured output: b'WMQDTDBH{Reverse_User_Kernel_Both_Analse}\n'
```

```
FLAG: WMQDTDBH{Reverse_User_Kernel_Both_Analse}
```

### 交叉验证

- loader 的 CRC32 用该 seed 通过（0x2000 字节，32 位 CRC）
- stage2 内嵌表 `0x4b0` == 模块 `wm_mix_key`
- stage2 发出的 tag `47cae5ef87d1222bbc2a01418e3045a4` == 用模块 `wm_do_verify` 公式复算得到的值（`wm/verify_module.py`），即真实模块会接受这次握手
- 最终字符串由二进制自身 `write` 产生

## 9. 复现步骤

```bash
# 1) seed
python3 emu_real.py                     # 需要未 strip 的 wm_kmod.ko
# 2) 解载荷
python3 finish.py 36f7a811d99d2fff7e65fa283a3780f0 loader
# 3) 跑 stage2 取输出
python3 run_stage2.py
# 4) （可选）模块侧 tag 校验
python3 verify_module.py
```

`emu_real.py` 与 `verify_module.py` 中的 `KO` 路径指向未 strip 的模块文件，按实际位置修改即可。

全程在用户态完成：解析 ELF、应用重定位、用 Unicorn 跑真实字节。发行包里那个 `.ko` 连 `insmod` 都加载不了，所以也只能这么干。

## 10. 脚本

### 10.1 `emu_real.py` —— 应用 RELA 重定位 + Unicorn 执行 SEED

```python
#!/usr/bin/env python3
"""Apply RELA relocations of the unstripped wm_kmod.ko and emulate the SEED ioctl path.
Layout: each section gets its own base; symbol values are section-relative."""
import struct, sys
from elftools.elf.elffile import ELFFile
from unicorn import *
from unicorn.x86_const import *

KO = "wm_kmod.ko"          # 指向未 strip 的模块（带 .symtab / .rela）
ef = ELFFile(open(KO, "rb"))

# assign bases
bases = {}
cur = 0x100000
for i, sec in enumerate(ef.iter_sections()):
    if sec.name in (".text", ".rodata", ".data", ".bss", ".init.text", ".exit.text") or sec.name.startswith((".rodata", ".data.")):
        bases[i] = cur
        cur += 0x20000
print("bases:", {ef.get_section(i).name: hex(b) for i, b in bases.items()})

# symbol address resolver
symtab = ef.get_section_by_name(".symtab")
def sym_addr(sym):
    shndx = sym["st_shndx"]
    if isinstance(shndx, int) and shndx in bases:
        return bases[shndx] + sym["st_value"]
    return 0

# image bytes
img = {}
for i, base in bases.items():
    sec = ef.get_section(i)
    data = bytearray(sec.data()) if sec["sh_type"] != "SHT_NOBITS" else bytearray(sec["sh_size"])
    img[base] = data

def sec_base_of_file_offset(shndx):
    return bases.get(shndx)

# apply relocations
applied = 0
for sec in ef.iter_sections():
    if sec["sh_type"] not in ("SHT_RELA", "SHT_REL"):
        continue
    target_idx = sec["sh_info"]
    if target_idx not in bases:
        continue
    tbase = bases[target_idx]
    buf = img[tbase]
    for rel in sec.iter_relocations():
        off = rel["r_offset"]; info = rel["r_info"]; addend = rel["r_addend"] if sec["sh_type"] == "SHT_RELA" else 0
        symidx = info >> 32; rtype = info & 0xffffffff
        S = sym_addr(symtab.get_symbol(symidx)) if symidx else 0
        P = tbase + off
        val = S + addend
        if rtype == 1:      # R_X86_64_64
            buf[off:off+8] = struct.pack("<Q", val & 0xffffffffffffffff)
        elif rtype in (2, 4):   # PC32 / PLT32
            buf[off:off+4] = struct.pack("<i", (val - P) & 0xffffffff if (val - P) >= 0 else (val - P))
            buf[off:off+4] = struct.pack("<I", (val - P) & 0xffffffff)
        elif rtype in (10, 11):  # 32 / 32S
            buf[off:off+4] = struct.pack("<I", val & 0xffffffff)
        elif rtype == 24:   # PC64
            buf[off:off+8] = struct.pack("<Q", (val - P) & 0xffffffffffffffff)
        else:
            pass
        applied += 1
print("relocations applied:", applied)

TEXT = bases[ef.get_section_index(".text")]
print("text base:", hex(TEXT))

mu = Uc(UC_ARCH_X86, UC_MODE_64)
for base, data in img.items():
    size = (len(data) + 0xfff) & ~0xfff
    mu.mem_map(base, max(size, 0x1000))
    mu.mem_write(base, bytes(data))
STACK = 0x6000000; UBUF = 0x5000000
mu.mem_map(STACK, 0x40000)
mu.mem_map(UBUF, 0x1000)

nonce = struct.pack("<Q", 0x66d82e9bc451a73f)
mu.mem_write(UBUF, nonce + b"\x00" * 16)
mu.reg_write(UC_X86_REG_RSP, STACK + 0x20000)
mu.reg_write(UC_X86_REG_RBX, UBUF)

CALL_FROM, CALL_TO = TEXT + 0x427, TEXT + 0x5a5
state = {"buf": None}

def hook(mu, addr, size, _):
    if addr == CALL_FROM:
        dst = mu.reg_read(UC_X86_REG_RDI); src = mu.reg_read(UC_X86_REG_RSI); n = mu.reg_read(UC_X86_REG_RDX)
        state["buf"] = dst
        mu.mem_write(dst, bytes(mu.mem_read(src, n)))
        mu.reg_write(UC_X86_REG_RAX, 0); mu.reg_write(UC_X86_REG_RIP, addr + size)
    elif addr == CALL_TO:
        mu.reg_write(UC_X86_REG_RAX, 0); mu.emu_stop()

mu.hook_add(UC_HOOK_CODE, hook)
try:
    mu.emu_start(TEXT + 0x3ff, TEXT + 0x700, count=500000)
except UcError as e:
    print("UC error:", e, "rip=%#x" % mu.reg_read(UC_X86_REG_RIP))

if state["buf"]:
    out = bytes(mu.mem_read(state["buf"], 0x18))
    print("resp:", out.hex())
    print("SEED:", out[8:].hex())
else:
    print("no buffer")
```

### 10.2 `finish.py` —— RC4 解密 + CRC32 校验

```python
#!/usr/bin/env python3
"""Finisher: given the 16-byte RC4 seed (hex), decrypt loader's WMPK payload,
verify CRC32 against the header field, and dump stage2.bin.

Usage: python3 finish.py <seed_hex_32chars> [loader]
Everything else (device, ioctl numbers, struct layout, RC4, CRC32, exec) is
already established statically; only the kernel-module-derived seed is missing.
"""
import struct, sys, zlib

seed_hex = sys.argv[1] if len(sys.argv) > 1 else "00" * 16
seed = bytes.fromhex(seed_hex)
assert len(seed) == 16, "seed must be 16 bytes"
ld = open(sys.argv[2] if len(sys.argv) > 2 else "loader", "rb").read()
DB = 0x3080                      # .data: vaddr 0x4080 -> file 0x3080
hdr = ld[DB + 0x20: DB + 0x38]   # vaddr 0x40a0
assert hdr[:4] == b"WMPK"
ln = struct.unpack("<I", hdr[12:16])[0]
expect = struct.unpack("<I", hdr[16:20])[0]
payload = ld[DB + 0x38: DB + 0x38 + ln]

def rc4(key, msg):
    S = list(range(256)); j = 0
    for i in range(256):
        j = (j + S[i] + key[i % len(key)]) & 0xff; S[i], S[j] = S[j], S[i]
    i = j = 0; out = bytearray(len(msg))
    for idx in range(len(msg)):
        i = (i + 1) & 0xff; j = (j + S[i]) & 0xff; S[i], S[j] = S[j], S[i]
        out[idx] = msg[idx] ^ S[(S[i] + S[j]) & 0xff]
    return bytes(out)

dec = rc4(seed, payload)
crc = zlib.crc32(dec)
print("seed=%s len=%#x expect_crc=%#x got_crc=%#x match=%s" % (seed.hex(), ln, expect, crc, crc == expect))
print("first32:", dec[:32].hex())
if crc == expect:
    open("stage2.bin", "wb").write(dec)
    print("wrote stage2.bin -> disassemble it (objdump -D -b binary -m i386:x86-64)")
```

### 10.3 `run_stage2.py` —— Unicorn 执行 stage2 并捕获输出

```python
#!/usr/bin/env python3
"""Run decrypted stage2 ELF under Unicorn with syscall stubs; capture its write() output."""
import struct
from unicorn import *
from unicorn.x86_const import *

BIN = open("stage2.bin", "rb").read()
BASE, STACK, ARG = 0x400000, 0x800000, 0x900000
mu = Uc(UC_ARCH_X86, UC_MODE_64)
mu.mem_map(BASE, 0x4000)
mu.mem_write(BASE, BIN)
mu.mem_map(STACK, 0x10000)
mu.mem_map(ARG, 0x1000)

seed = bytes.fromhex("36f7a811d99d2fff7e65fa283a3780f0")
blob = bytes.fromhex("80766664c4aa93a736c8451d4afaa26ab87669")
nonce = struct.pack("<Q", 0x66d82e9bc451a73f)
# struct: magic 'TCMW'(4) + fd(4) + nonce(8) + seed(16)
mu.mem_write(ARG, b"TCMW" + struct.pack("<I", 3) + nonce + seed)
mu.reg_write(UC_X86_REG_RDI, ARG)
mu.reg_write(UC_X86_REG_RSP, STACK + 0x8000)

out = []
def hook_code(mu, addr, size, _):
    if mu.mem_read(addr, 1) == b"\x0f" and mu.mem_read(addr+1, 1) == b"\x05":  # syscall
        nr = mu.reg_read(UC_X86_REG_RAX)
        a1, a2, a3 = (mu.reg_read(r) for r in (UC_X86_REG_RDI, UC_X86_REG_RSI, UC_X86_REG_RDX))
        if nr == 101:            # ptrace
            mu.reg_write(UC_X86_REG_RAX, 0)
        elif nr == 16:           # ioctl
            if a2 == 0xC0445703:                     # BLOB -> 68-byte wm_blob
                mu.mem_write(a3, struct.pack("<I", len(blob)) + blob.ljust(0x40, b"\x00"))
                mu.reg_write(UC_X86_REG_RAX, 0)
            elif a2 == 0x40205702:                   # VERIFY -> accept
                print("TAG_SENT:", bytes(mu.mem_read(a3, 16)).hex())
                mu.reg_write(UC_X86_REG_RAX, 0)
            else:
                mu.reg_write(UC_X86_REG_RAX, 0)
        elif nr == 1:            # write
            out.append(bytes(mu.mem_read(a2, a3)))
            mu.reg_write(UC_X86_REG_RAX, a3)
        elif nr in (60, 231):    # exit
            mu.emu_stop()
        else:
            mu.reg_write(UC_X86_REG_RAX, 0)
        mu.reg_write(UC_X86_REG_RIP, addr + size)

mu.hook_add(UC_HOOK_CODE, hook_code)
try:
    mu.emu_start(BASE + 0x24b, 0, count=200000)
except UcError as e:
    print("UC error:", e, "rip=%#x" % (mu.reg_read(UC_X86_REG_RIP) - BASE))
print("rax(return):", hex(mu.reg_read(UC_X86_REG_RAX)))
print("captured output:", b"".join(out))
```

### 10.4 `verify_module.py` —— 复现模块端 tag 校验

```python
#!/usr/bin/env python3
"""Apply relocations to wm_kmod.ko, run SEED then wm_do_verify, check the tag stage2 sent."""
import struct
from elftools.elf.elffile import ELFFile
from unicorn import *
from unicorn.x86_const import *

ef = ELFFile(open("wm_kmod.ko", "rb"))     # 指向未 strip 的模块
bases = {}
cur = 0x100000
for i, sec in enumerate(ef.iter_sections()):
    if sec.name in (".text", ".rodata", ".data", ".bss", ".init.text", ".exit.text") or sec.name.startswith((".rodata", ".data.")):
        bases[i] = cur; cur += 0x20000
symtab = ef.get_section_by_name(".symtab")
def sym_addr(s):
    idx = s["st_shndx"]
    return bases[idx] + s["st_value"] if isinstance(idx, int) and idx in bases else 0
img = {}
for i, b in bases.items():
    sec = ef.get_section(i)
    img[b] = bytearray(sec.data()) if sec["sh_type"] != "SHT_NOBITS" else bytearray(sec["sh_size"])
for sec in ef.iter_sections():
    if sec["sh_type"] not in ("SHT_RELA", "SHT_REL") or sec["sh_info"] not in bases:
        continue
    tb = bases[sec["sh_info"]]; buf = img[tb]
    for rel in sec.iter_relocations():
        off = rel["r_offset"]; info = rel["r_info"]
        add = rel["r_addend"] if sec["sh_type"] == "SHT_RELA" else 0
        S = sym_addr(symtab.get_symbol(info >> 32)) if (info >> 32) else 0
        P = tb + off; t = info & 0xffffffff; val = S + add
        if t == 1: buf[off:off+8] = struct.pack("<Q", val & (2**64-1))
        elif t in (2, 4): buf[off:off+4] = struct.pack("<I", (val - P) & 0xffffffff)
        elif t in (10, 11): buf[off:off+4] = struct.pack("<I", val & 0xffffffff)
        elif t == 24: buf[off:off+8] = struct.pack("<Q", (val - P) & (2**64-1))
TEXT = bases[ef.get_section_index(".text")]

mu = Uc(UC_ARCH_X86, UC_MODE_64)
for b, d in img.items():
    mu.mem_map(b, (len(d) + 0xfff) & ~0xfff); mu.mem_write(b, bytes(d))
STACK, UBUF = 0x6000000, 0x5000000
mu.mem_map(STACK, 0x40000); mu.mem_map(UBUF, 0x2000)
nonce = struct.pack("<Q", 0x66d82e9bc451a73f)

st = {"buf": None}
def hook(mu, addr, size, _):
    if addr == TEXT + 0x427:
        dst = mu.reg_read(UC_X86_REG_RDI)
        st["buf"] = dst
        mu.mem_write(dst, bytes(mu.mem_read(mu.reg_read(UC_X86_REG_RSI), mu.reg_read(UC_X86_REG_RDX))))
        mu.reg_write(UC_X86_REG_RAX, 0); mu.reg_write(UC_X86_REG_RIP, addr + size)
    elif addr == TEXT + 0x5a5:
        mu.reg_write(UC_X86_REG_RAX, 0); mu.emu_stop()
mu.hook_add(UC_HOOK_CODE, hook)

# 1) SEED
mu.mem_write(UBUF, nonce + b"\x00" * 16)
mu.reg_write(UC_X86_REG_RSP, STACK + 0x20000); mu.reg_write(UC_X86_REG_RBX, UBUF)
try: mu.emu_start(TEXT + 0x3ff, TEXT + 0x700, count=300000)
except UcError as e: print("seed run err:", e)
seed = bytes(mu.mem_read(st["buf"] + 8, 16)) if st["buf"] else b""
print("module SEED:", seed.hex())

# 2) VERIFY with the tag stage2 sent
tag = bytes.fromhex("47cae5ef87d1222bbc2a01418e3045a4")
mu.mem_write(UBUF + 0x100, tag + b"\x00" * 16)
mu.reg_write(UC_X86_REG_RSP, STACK + 0x20000)
mu.reg_write(UC_X86_REG_RDI, UBUF + 0x100)
try:
    mu.emu_start(TEXT + 0x160, TEXT + 0x2d0, count=300000)
    print("wm_do_verify ret =", mu.reg_read(UC_X86_REG_RAX))
except UcError as e:
    print("verify err:", e, "rip=%#x" % (mu.reg_read(UC_X86_REG_RIP) - TEXT))
```
